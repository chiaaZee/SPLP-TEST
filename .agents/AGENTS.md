# Project-Scoped Rules

## Wireframe Design Guidelines
Whenever generating visual wireframes for this project, you must follow these precise guidelines:

1. **Color & Style**:
   - Must be strictly 100% black-and-white (grayscale).
   - No color gradients, no drop shadows, and no colored emoji/glyph characters of any kind (e.g., remove waving hands, colored warning badges, etc.).
   - Use clean, flat vector outline styling on a solid white background.

2. **Icons vs. Image Placeholders**:
   - **Vector Icons**: Keep user interface icons intact and visible (e.g., sidebar navigation icons, stats card outline icons, header buttons).
   - **Image Placeholders**: Use schematic boxes with a diagonal "X" across them strictly for actual image files and brand logos (e.g. the main crest/logo in the sidebar).

3. **Text & Content**:
   - Align layouts to match reference screenshots precisely.
   - Text can be represented by clean outline typography for headings and simple straight horizontal lines for paragraph blocks.

4. **Composition**:
   - Generate only the layout mockup itself. Do not include mock device frames (such as browser windows, laptop screen borders, tablet, or phone casings) unless explicitly requested.
